    Liquid

    Any shape can hold liquid — box, sphere, cylinder, or one you drew yourself (a hand-drawn vase keeps its own narrow-neck / wide-belly silhouette). Turn this object into a container to fill it.

    Sealed = a fully enclosed vessel, like a snow globe or a sealed decorative orb — the liquid inside sloshes when you rotate or shake it but can never pour out. Works on any container; pairs especially well with a Sphere (Add Shape → Sphere → Make This a Container), since the liquid then hugs the ball's own curved interior instead of sitting in a flat-sided puddle.

    Amount (this layer)
    Viscosity (thin ↔ honey-thick)
    Opacity

    Thicker liquid ripples less, settles slower, and pours out more slowly when tipped — applies to the topmost layer.

    Stack more than one liquid in the same container — like oil floating on water — by picking a color and amount, then clicking Add Liquid Layer again. Tipping pours the topmost layer out first.

    Liquid Detail (subdivision)

    Pushed all the way up, this is a genuinely huge simulation grid (tens of thousands of cells) — great for a still or slow-mo shot, but it will cost real frame rate on slower machines.

    Higher detail = a real per-cell wave simulation (like a light Navier–Stokes solver) instead of one flat tilted plane — ripples actually spread out and bounce off the walls.

    Mimics stacked CSS box-shadow neon layers: a bright core color, a spread-out colored glow, and an optional flicker.

    Tilt (Rotate tool or RX/RZ) or drag (Move tool) this container to make the liquid slosh and splash. Tip it past ~55° and it will pour out — unless Sealed is on, in which case it just keeps sloshing no matter how far you flip it.

    Select or add an object to edit its transform and material.

    Controls

    • Left-drag on empty space — orbit the camera.
    • Click an object — select it (shown with a yellow outline).
    • Right-drag — pan the camera.
    • Scroll wheel — zoom in / out.
    • Pick Move / Rotate / Scale in the right panel, then drag directly on the selected object to transform it. Use the number fields for precise values.
    • Turn any object into Metal, Paper or Glass from the Material panel.
    • Drawing toolbar (top of the viewport): Hand H, Select V/1, Rectangle R/2, Diamond D/3, Ellipse O/4, Arrow A/5, Line L/6, Draw P/7, Text T/8, Import 9, Eraser E/0. Q locks the current tool.
    • Import (9): drop it on the floor to open an Import Portal: a glowing floor circle with an energy orb above it. Drag the big red point (it stays inside the circle) to steer the orb; double-click it to recenter. Click the orb to import an image. Drag the rim to move the portal; ✕ removes it.
    • Control (C): drop it on the floor to get a control pad lying on the floor, wired to a new 3D cube by a neon wire. Click one of the 9 colors to recolor the cube; the code blocks and layer panel are decorative. Drag the pad's header to slide it; move the cube and watch the cable swing.
    • Toolbox (B): drag it onto the floor (or press B and click the floor). A real 3D toolbox drops in, its lid swings open, trays slide out and hologram panels offer shapes, containers, lights, materials, liquids and scene actions. Move it like any object; click it while selected to open/close the lid; ✕ puts it away.
    • Drawings: drag to move, corner handles to resize (Shift keeps proportions), double-click text to edit, Delete removes, Ctrl+D duplicates, arrow keys nudge, Ctrl+Z / Ctrl+Y undo/redo.
    • Add a Box Tray or Glass Cup container, then use the Liquid panel to fill it — tilt or rotate the container (Rotate tool, or RX/RZ fields) to see it slosh.
